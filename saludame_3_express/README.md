# Salúdame 3

Crea una aplicación en Express que en la ruta `/` muestre un formulario con un campo de texto para escribir un nombre.

- Al enviar el formulario (`POST /`) debe saludar con el nombre escrito, por ejemplo **Hola Pedro!**

Usa una vista `pug` para el formulario.

## Cómo ejecutarlo

```bash
npm install
node app.js
```

Abre http://localhost:3000
